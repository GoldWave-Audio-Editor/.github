# GoldWave — waveform editor with batch effects

GoldWave keeps one named board on the desk: the live waveform, the batch pass in front of you, and a short note the next editor can read. Extra files wait for their own title.

## Session Card

| Slice | What you do in GoldWave | What remains |
|-------|------------------------|--------------|
| Arrival | Open GoldWave and name today's sound desk | A titled audio editor |
| Focus | Keep only live files on the GoldWave board | A short waveform list |
| Check | Read GoldWave batch effects before a large pass | A confirmed file set |
| Handoff | Mark finished edits inside GoldWave | A note for the next visit |

## How GoldWave Sits

GoldWave does not replace the player, the unnamed dump folder, or the extra trial windows you already leave open. It sits beside them as a named sound desk for one job: which audio editor is live, which waveform still matches the batch effects, and what the next person should read.

If two people share a sound PC, each keeps a GoldWave style of their own. Extra files wait for their own title instead of crowding the live waveform.

A first visit should be one short batch pass, then the same GoldWave sound desk the next day. That is enough to see if the named audio edit holds.

## Traffic Light

| Signal | On the GoldWave board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live waveform list | Continue the same audio editor |
| Amber | Two jobs mixed in one batch | Split the files before a large pass |
| Red | No title, no note, trial windows everywhere | Stop and name the sound desk first |
| Clear | Handoff written, live files few | Close GoldWave and leave the sound desk |

## Open Order

1. Open the last GoldWave sound desk, not a new empty audio editor.
2. Read the waveform and the last handoff.
3. Finish one visible batch effects pass inside GoldWave.
4. Write what changed, then close with fewer stray trial windows than you found.
5. If the desk feels crowded, drop anything that belongs to a different GoldWave job.

## After a Week

A week in GoldWave is not a larger pile of trial windows. It is the same title, a shorter live waveform list, and a note that still makes sense before the next batch. Take finished files off the live set so the next visit starts on the sound desk that is still open.

Other programs stay where they are. GoldWave only keeps the path back: desk name, waveform, batch effects, handoff.

## Sign-off

- [ ] The GoldWave workspace name is short enough to scan
- [ ] Only live files sit on the waveform
- [ ] A second person can read the edit handoff
- [ ] The last GoldWave sound desk still opens after a restart

## Field Note

GoldWave is easier to trust when the sound desk stays smaller than the trial-window pile it came from. Name the edit, keep the live waveform, finish one visible batch pass, and write what changed.
